# 나그네 마을 원본 조각

`assets/ark-game.js`는 **이 폴더에서 만들어지는 파일**이다. 직접 고치지 않는다(In Odyssey의 `odyssey-src`와 같은 방식).

```
조각 수정 → python ark-src/build.py → 게임 시험 → 커밋(조각 + assets/ark-game.js + ark.html)
```

- 게임은 예전과 똑같이 파일 하나로 배포된다. 코드 전체가 하나의 함수 안에서 변수를 공유하므로 조각끼리 자유롭게 부를 수 있다.
- `PARTS` 순서를 바꾸지 않는다. 조각 하나만 따로 실행할 수는 없다.
- `build.py`가 `ark.html`의 `ark-game.js?v=` 캐시 번호를 내용에 맞게 자동으로 바꾼다(손으로 고치지 않는다).
- 푸시하면 GitHub Actions(`ark-src-check.yml`)가 조각과 게임 파일이 맞는지 확인하고, 다르면 실패 메일을 보낸다.
- 찾을 때: `grep -n "함수이름" ark-src/js/*.js`
