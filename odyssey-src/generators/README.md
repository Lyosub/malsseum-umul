- 이 저장소는 공개라서 **개역개정 원문 파일(`1sa8.txt` 등)은 넣지 않았다.** 볼트의 `50. Projects/50_0. Active/In Odyssey 원문 (생성 스크립트 입력)/<편>/`에 있으니, 스크립트와 같은 폴더에 복사해서 쓴다(생성 결과와 함께 이 폴더에 커밋하지 않는다).

- 비밀값(토큰, 관리 코드, API 키)은 어떤 파일에도 적지 않는다. SQL 실행 스크립트는 옮기지 않았다.
